# 図版制作指示書（Claude用図版プロンプト）

## 基本情報
- 図版ID: WH-C15-L-02
- 図版名: アフリカ分割（地域別の主要支配国・模式図）＝資料B
- 対応問題ID: WH-CH15 第2問（アフリカ分割）／第3問の背景理解／第10問
- 必要資料の種類: 新規作成の模式地図（SVG＋PNG）
- 図の目的: 地域ごとの主要支配国の分布と、分割を促した要因を1枚で対照させる。
- 対象年代: 1880年代〜1912年頃（アフリカ分割期）
- 地理的範囲: アフリカ大陸全域（簡略輪郭。国境線は描かない）

## 作図内容
- 左: アフリカ大陸の簡略輪郭を4地域に塗り分け（境界は白線）。
  - 北部（仏・英） / 西部（仏中心） / 東部（英中心） / 中・南部（英・仏・ベルギー等）
  - 「中・南部」の支配国注記は輪郭内に収まらないため、引き出し線で輪郭外右に配置。
- 右: 枠囲み「分割を促した要因」
  - ベルリン会議（1884〜85年） / 資源・市場・交通路の確保 / 「実効支配」原則 / 列強間の競争
- 右下注記: 「例外として独立を維持：エチオピア、リベリア」（国名は科目色で強調）

## 表示しない情報（正答露出防止）
- 「実効支配」の定義文は書かない（第2問の答えになるため、語句のみ提示）。
- エチオピア・リベリアの位置は地図上に示さない（第2問で問うのは国名のみ。文字情報として提示済みのため位置まで示すと過剰）。

## 体裁
- サイズ: 幅160mm（社会系L）・高さ約95mm（上限100mm以内）
- 配色: 地域は紺系・金茶系の薄い濃淡4段階（白黒印刷でも判別可）。海は薄灰。
- フォント: ゴシック。地域名9pt相当・注記8pt相当。
- PNG解像度: 300dpi

## 作図根拠・出典
- 詳説世界史（世界史探究・山川出版社）第15章 アフリカ分割の記載事実（英仏の縦断・横断政策、ベルギー領コンゴ、独立維持2国）。
- 縮尺・輪郭は学習用の模式表現。市販地図のトレースではない。
